# 3-Force Flying Cup Challenge

중학교 1학년 과학 **「여러 가지 힘」** 단원에서 사용할 수 있는  
**종이컵 비행체 기반 수행평가 및 탐구 활동용 웹앱**입니다.

학생들은 종이컵 비행체를 직접 제작하고,  
**탄성력 · 마찰력 · 중력**에 대한 수업에서 배운 개념을 이용하여  
비행 거리를 개선하는 설계를 수행합니다.

이 활동의 핵심은 단순히 **가장 멀리 날리는 것**이 아니라,

> **배운 힘의 개념을 실제 문제 해결에 적용하고,  
> 실험 결과를 측정 자료와 과학적 근거로 설명하는 것**

입니다.

---

## 1. 수업 대상

- 대상: 중학교 1학년
- 관련 단원: 여러 가지 힘 / 힘과 운동
- 권장 수업 시간: **45분**
- 수업 형태: 모둠별 제작 및 실험 + 개별 결과 해석
- 활용 형태:
  - 수행평가
  - 탐구 활동
  - 공학적 문제 해결 활동
  - 힘 단원 종합 정리 활동

---

## 2. 학습 목표

학생들은 활동을 통해 다음 내용을 학습합니다.

1. **탄성력**이 물체의 운동을 변화시키는 과정을 설명할 수 있다.
2. **마찰력**이 단순히 운동을 방해하는 힘이 아니라, 운동을 전달하거나 가능하게 하는 역할도 할 수 있음을 이해한다.
3. **중력**이 비행 중인 물체에 지속적으로 작용함을 설명할 수 있다.
4. 한 번에 한 가지 조건만 바꾸는 **변인 통제**의 필요성을 이해한다.
5. 반복 측정값과 평균을 이용하여 실험 결과를 비교할 수 있다.
6. 실험 결과를 힘의 개념과 연결하여 과학적으로 설명할 수 있다.

---

## 3. 활동 개요

학생들은 같은 크기의 종이컵 2개를 바닥끼리 연결하여 비행체를 제작합니다.

고무줄을 종이컵의 연결 부분에 감은 뒤 일정한 길이만큼 당겨 발사하면,  
고무줄이 풀리면서 비행체가 앞으로 이동하고 회전합니다.

기본형 비행체의 비행 거리를 측정한 뒤, 학생들은 다음과 같은 설계 요소 중 하나를 변경합니다.

- 고무줄을 당기는 길이
- 고무줄을 감는 횟수
- 비행체의 질량
- 기타 교사가 허용한 한 가지 설계 변수

이후 개선형 비행체의 비행 거리를 다시 측정하고 기본형과 비교합니다.

---

## 4. 핵심 과학 개념

### 탄성력

늘어난 고무줄이 원래 길이로 돌아가려 하면서  
비행체의 운동 상태를 변화시킵니다.

### 마찰력

고무줄과 종이컵이 접촉하는 부분의 마찰 때문에  
고무줄의 움직임이 종이컵의 회전 운동으로 전달됩니다.

이 활동은 학생들이 흔히 가지는

> **“마찰력은 항상 운동을 방해한다.”**

라는 오개념을 수정하는 데 활용할 수 있습니다.

### 중력

비행 중인 종이컵 비행체에는 지구가 아래쪽으로 잡아당기는 중력이 작용합니다.

---

## 5. 중요한 과학적 구분

탄성력, 마찰력, 중력이 비행 내내 동일한 방식으로 작용하는 것은 아닙니다.

- **탄성력**: 주로 발사 과정에서 작용
- **고무줄과 종이컵 사이의 마찰력**: 발사 과정에서 회전을 전달
- **중력**: 비행 중 지속적으로 작용

고무줄이 종이컵에서 완전히 떨어진 뒤에는  
고무줄의 탄성력이 더 이상 비행체를 앞으로 미는 힘으로 직접 작용하지 않습니다.

또한 회전하는 종이컵이 예상보다 오래 떠 있거나 위쪽으로 휘어가는 현상은  
중학교 1학년에서 배우는 세 가지 힘만으로 완전히 설명하기 어렵습니다.

이 현상은 확장 개념으로 **마그누스 효과(Magnus effect)**와 연결할 수 있습니다.

---

## 6. 45분 수업 흐름

| 시간 | 활동 |
|---|---|
| 0~5분 | 교사 시범 및 현상 관찰 |
| 5~12분 | 기본형 종이컵 비행체 제작 |
| 12~18분 | 기본형 비행거리 3회 측정 |
| 18~25분 | 힘 분석 및 변경할 변인 선택 |
| 25~36분 | 개선형 제작 및 3회 측정 |
| 36~45분 | 평균 비교 및 개별 결과 해석 |

---

## 7. 수행평가의 핵심 원칙

이 활동에서는 **비행거리 자체를 점수로 평가하지 않습니다.**

학생의 과학적 사고와 적용 능력을 평가합니다.

평가의 핵심은 다음 네 영역입니다.

| 평가 영역 | 배점 |
|---|---:|
| 힘의 개념 이해 | 30점 |
| 설계 근거 | 25점 |
| 실험 수행 | 20점 |
| 결과 해석 | 25점 |
| **합계** | **100점** |

---

## 8. 평가에서 확인하는 내용

### 힘의 개념 이해

- 탄성력, 마찰력, 중력을 실제 상황과 연결할 수 있는가?
- 각 힘이 언제, 어디에서 작용하는지 구분할 수 있는가?

### 설계 근거

- 변경한 변인을 힘의 개념과 연결하여 설명할 수 있는가?
- 단순한 추측이 아니라 과학적 근거를 제시하는가?

### 실험 수행

- 한 번에 한 가지 조건만 변경했는가?
- 동일한 조건에서 반복 측정했는가?
- 3회 측정 후 평균을 이용했는가?

### 결과 해석

- 기본형과 개선형의 측정값을 비교할 수 있는가?
- 결과가 달라진 이유를 관련 힘의 개념으로 설명할 수 있는가?

## 9. 웹앱 주요 기능

이 프로젝트는 별도의 서버 없이 실행되는 **단일 HTML 파일**입니다.

### 학생 기능

- 종이컵 비행체 제작 안내
- 탄성력 · 마찰력 · 중력 개념 참고
- 45분 수업 진행 흐름
- 수행평가 문항 입력
- 기본형 / 개선형 비행거리 기록
- 3회 측정 평균 자동 계산
- 성능 향상 거리 자동 계산
- 실험 결과 자동 저장
- 학생 기록 JSON 파일 저장

### 교사 기능

- 교사 평가 모드
- 학생 기록 JSON 불러오기
- 4영역 루브릭 평가
- 총점 100점 자동 환산
- 교사 피드백 입력
- 평가 결과 JSON 저장
- 평가 결과 CSV 저장
- 학생용 / 교사용 A4 인쇄

## 10. 실행 방법

별도의 설치가 필요하지 않습니다.

1. 아래 HTML 파일을 다운로드합니다.

```text
중1_종이컵비행체_3힘_수행평가앱.html
```

2. 파일을 더블클릭합니다.

3. Chrome, Edge, Safari 등의 웹브라우저에서 실행합니다.

인터넷 연결 없이도 대부분의 기능을 사용할 수 있습니다.

---

## 11. 학생 사용 방법

1. 학년·반·번호·이름·모둠을 입력합니다.
2. 제작 안내를 참고하여 기본형 비행체를 만듭니다.
3. 기본형 비행거리를 3회 측정합니다.
4. 개선할 한 가지 변인을 선택합니다.
5. 해당 변인이 어떤 힘과 관련되는지 예측합니다.
6. 개선형 비행체를 제작합니다.
7. 개선형 비행거리를 3회 측정합니다.
8. 기본형과 개선형의 평균 비행거리를 비교합니다.
9. 개별 결과 해석 문항을 작성합니다.
10. 필요하면 **학생 기록 JSON 파일**을 저장하여 제출합니다.

---

## 12. 교사 사용 방법

화면 상단의 **교사 평가 모드** 버튼을 선택합니다.

학생이 제출한 JSON 파일을 불러오면 학생의 기록을 확인할 수 있습니다.

이후 다음 네 영역을 각각 1~4수준으로 평가합니다.

- 힘의 개념 이해
- 설계 근거
- 실험 수행
- 결과 해석

평가 결과는 자동으로 100점 기준으로 환산됩니다.

평가 결과는 다음 형식으로 저장할 수 있습니다.

```text
JSON
CSV
```

CSV 파일은 Excel 또는 Google Sheets에서 열어 학생별 점수를 취합할 수 있습니다.

## 13. 데이터 저장 방식

학생이 입력한 내용은 기본적으로 웹브라우저의

```text
localStorage
```

에 저장됩니다.

따라서 별도의 서버나 데이터베이스가 필요하지 않습니다.

주의할 점:

- 같은 컴퓨터와 같은 브라우저에서는 입력 내용이 유지됩니다.
- 브라우저 데이터 또는 사이트 저장 정보를 삭제하면 기록이 사라질 수 있습니다.
- 학생 제출용으로는 JSON 파일 저장 기능을 함께 사용하는 것을 권장합니다.

## 17. GitHub Pages에서 배포하기

이 앱은 정적 HTML 파일이므로 GitHub Pages에서 쉽게 배포할 수 있습니다.

### 가장 간단한 방법

1. GitHub 저장소를 생성합니다.
2. HTML 파일의 이름을 다음과 같이 변경합니다.

```text
index.html
```

3. `index.html`과 `README.md`를 저장소에 업로드합니다.
4. GitHub 저장소에서

```text
Settings
→ Pages
→ Deploy from a branch
```

를 선택합니다.

5. `main` 브랜치와 `/root`를 선택합니다.

배포가 완료되면 학생들이 URL로 접속할 수 있습니다.

---

## 18. Vercel에서 배포하기

GitHub 저장소와 Vercel을 연결하면 동일한 앱을 웹서비스로 배포할 수 있습니다.

1. GitHub 저장소에 `index.html`을 업로드합니다.
2. Vercel에 로그인합니다.
3. **Add New Project**를 선택합니다.
4. 해당 GitHub 저장소를 선택합니다.
5. 별도의 Build Command 없이 배포합니다.

단일 정적 HTML 파일이므로 별도의 프레임워크 설정이 필요하지 않습니다.
